# AGENTS.md

This file provides guidance to WARP (warp.dev) when working with code in this repository.

## Project Overview

Band website for **Batham**, built with Nuxt 3. Content is managed externally in Contentful (headless CMS) and fetched at runtime via the Contentful Delivery API.

## Commands

- `npm run dev` — Start dev server on http://localhost:3000
- `npm run build` — Production build (outputs to `.output/`)
- `npm run start` — Run the production build (`node .output/server/index.mjs`)
- `npm run preview` — Preview production build via Nuxt
- `npm run generate` — Static site generation
- `npx eslint .` — Lint (ESLint config is generated by Nuxt via `@nuxt/eslint`)

There is no test framework configured in this project.

## Environment Variables

Contentful credentials are required and loaded from `.env`:

- `VUE_APP_CTF_SPACE_ID` — Contentful space ID
- `VUE_APP_CTF_CDA_ACCESS_TOKEN` — Contentful Content Delivery API access token

These are exposed to the client via `nuxt.config.ts` → `runtimeConfig.public` and accessed with `useRuntimeConfig()`.

## Architecture

This is a single-page site — there is no `pages/` directory and no client-side routing. `app.vue` is the sole entry point and renders all content.

### Nuxt Modules

The following modules are configured in `nuxt.config.ts` and available globally:

- `@nuxt/ui` — UI component library (includes Tailwind-based components)
- `@nuxt/icon` — Icon component (`<Icon name="..." />`); used in `MainNavigation.vue`
- `@nuxt/image` — Optimized image component (`<NuxtImg>`)
- `@nuxt/fonts` — Automatic font optimization
- `@nuxt/scripts` — Third-party script management
- `@nuxt/eslint` — ESLint integration

### Content Flow

1. `app.vue` creates a Contentful client and fetches a `websitePage` entry by slug (`/`) with `include: 4` for deep linking. It iterates over the entry's `content` field.
2. Each content section has a `type` field (array). The first element determines which block component renders it: `Hero`, `Rich Text`, or `Video`.
3. All block components render Contentful rich text to HTML via `documentToHtmlString` from `@contentful/rich-text-html-renderer` and inject it with `v-html`. New content blocks should follow this same pattern.

### Components

- **`MainNavigation.vue`** — Top nav bar with logo and social media icon links (YouTube, Instagram, Bandcamp). Uses `@nuxt/icon` for icons.
- **`HeroBlock.vue`** — Renders hero images/headings. Has special handling for entries tagged `promo` (wraps in an `<a>` linking to the asset file).
- **`TextBlock.vue`** — Renders a title and rich text body. Also contains global styles for `.body`, `iframe`, and `.cta-btn` classes.
- **`VideoBlock.vue`** — Extracts hyperlinks from rich text content and renders them as YouTube iframes.

### Styling

- SCSS (`lang="scss"`) is used throughout, powered by `sass-embedded`.
- Color scheme: gold (`#d9ae03`) on black (`#000`).
- Custom font "ACharmingFont" is loaded from `assets/fonts/Achafont.ttf` via `@font-face` in `app.vue`.
- Global layout styles (`.body`, `iframe`, `.cta-btn`) live in `app.vue` alongside the base `body`/`html` reset.
